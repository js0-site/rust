# u64_2 性能评测

本目录包含 u64_2 库的性能评测代码和结果。

## 评测内容

### 1. 编码/解码基础性能

- 测试不同大小数字的编码和解码性能
- 覆盖从单字节到八字节的所有情况
- 包括边界值和特殊值测试

### 2. 组合操作性能

- 测试编码后立即解码的完整流程性能
- 模拟实际使用场景

### 3. 吞吐量测试

- 测试处理大量数据时的性能表现
- 评估算法在大规模数据处理中的效率

## 运行评测

```bash
# 运行所有评测
cargo bench

# 运行特定评测组
cargo bench encode_decode
cargo bench encode_decode_combined
cargo bench throughput

# 生成详细报告
cargo bench -- --output-format html
```

## 性能特点

### 编码性能

- 使用位运算快速计算所需字节数
- 避免分支预测，提高执行效率
- 使用 unsafe 指针操作，减少边界检查开销

### 解码性能

- 利用查找表快速应用掩码
- 非对齐内存读取，在现代 CPU 上性能良好
- 单次读取多个字节，减少内存访问次数

### 内存效率

- 紧凑编码，最小化存储空间
- 预分配固定大小缓冲区，避免动态分配
- 零拷贝设计，减少内存移动

## 优化策略

1. **查找表优化**: 使用预计算的掩码查找表，避免运行时计算
2. **位运算优化**: 使用位运算替代除法和取模运算
3. **内存访问优化**: 减少内存访问次数，提高缓存命中率
4. **分支消除**: 使用位运算消除条件分支，提高分支预测成功率

## 测试环境

- CPU: Apple M2 (或其他测试环境)
- 内存: 统一内存架构
- 编译器: rustc (最新稳定版)
- 优化级别: release (默认)

## 结果分析

评测结果会显示在不同数据大小下的性能表现，包括：

- 编码时间 (ns/iter)
- 解码时间 (ns/iter)
- 吞吐量 (MB/s)
- 内存使用情况

这些数据可以帮助理解算法在不同场景下的性能特征，并为进一步的优化提供指导。
